# 少年股神 · THE TEENAGE ORACLE

> 十六歲，你拿壓歲錢開了戶。二十四年後結算：淨值、心態、還剩幾個朋友。
> **賺錢不難，難的是不變成另一個人。**

一款種子化的台股人生模擬器。單一 HTML 檔、零依賴、零建置流程——下載打開就能玩。

## 玩法

從 16 歲開戶到 40 歲結算，每年做三件事：

1. **分配精力骰**（3–6 顆）到 盤感・心性・情報・紀律・研究・人脈——或者拿去陪家人、徹底休息、加班接案
2. **回應事件卡**（81 張，抽過不重複）
3. **決定部位**（空手到全押 2.6 倍槓桿）

十九歲時選一次**流派**，不可逆：存股派／波段派／當沖派／套利派／長線派。同一顆種子換流派＝五條完全不同的路。

## 種子

`?seed=xxxxx` 決定這二十四年的完整牛熊。**相同種子＋相同選擇＝相同人生。**

- **戰帖**：結局頁可複製一條把整局結果編碼進去的網址（152 字元，不需後端）。對方拿到同一顆種子，而且你的淨值曲線會變成他畫面上的灰線。
- **鬼影**：同一顆種子重玩時，上一局的曲線會疊在你的線上。
- **圖鑑**：24 種結局、10 種特質、5 種流派的解鎖進度存在 localStorage。

## 兩條階梯

借自棒球生涯模擬的結構——聯盟階級，以及球團要不要跟你續約。

**資本階級**（你站在哪個舞台，會掉下去）
`散戶 → 中實戶 600萬 → 大戶 3000萬 → 隱形富豪 1.5億`

**受託關係**（有沒有人要你）
`自己的錢 → 家人的錢 → 朋友湊的 → 代操合約 → 私募基金`

管別人的錢會抽管理費 1.5% 與績效費 15%，但連兩年虧損就會被贖回。虧損年還得對投資人交代——照實說、強調長期、或者年底做帳把難看的部位換掉。

三十三歲還在散戶這一層，槓桿選項會永久消失。不是規則禁止你，是你輸不起了。

## 對照組

結局會拿你跟三個同期、大盤、台積電算總帳。兩條對照線都用**跟你一模一樣的薪水、每年全部投入**去跑，所以差距完全來自選擇，不是本金。

## 技術

單檔 HTML，約 128 KB，沒有框架、沒有打包工具、沒有後端。

- **PRNG**：xmur3 字串雜湊 + mulberry32。整份程式只有一個隨機狀態。
- **鐵律**：任何純呈現層（動畫、圖表、HUD、時間軸）一律禁止呼叫 `R()`。骰子的滾動動畫刻意用 `Math.random()`——多消耗一次種子化亂數，後面整條人生就會錯位。
- **行情**：markov 鏈生成，校準到稳態算術年均約 11.9%、**幾何年化約 7.8%**。幾何遠低於算術是刻意的——波動本身就在吃掉報酬，那是這款想講的第一件事。
- **儲存**：localStorage 只放 UI 偏好、圖鑑與種子歷史，全部包在 try/catch 裡。沒有 localStorage 時遊戲照常能玩。

## 本機執行

```bash
open index.html      # macOS
```

不需要 server。若要自架：把 `index.html` 放到任何靜態主機即可。
