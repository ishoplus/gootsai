> 十六歲，你拿壓歲錢開了戶。二十四年後結算：淨值、心態、還剩幾個朋友。
> **賺錢不難，難的是不變成另一個人。**

一款種子化的台股人生模擬器。單一 HTML 檔、零依賴、零建置流程——下載打開就能玩。

## 玩法

從 16 歲開戶到 40 歲結算，每年做三件事：

1. **分配精力骰**（3–6 顆）到 盤感・心性・情報・紀律・研究・人脈——或者拿去陪家人、徹底休息、加班接案
2. **回應事件卡**（81 張，抽過不重複）
   - **15 張**招牌卡的每個選項有自己的後果，而且不是每個決定都要擲骰：
     「把當沖權限關掉」就是關掉了，沒有成不成功的問題
   - **5 張**根本沒得選——「市場休市一週」的敘述自己就寫著「你什麼都不能做，只能等」，
     硬給三個風險檔次只會讓題目跟選項脫節
   - 其餘走保守／照常／全力三檔，那些卡的本質本來就是「你要冒多大險」
3. **決定今年這筆錢放哪裡**——空手、高股息 ETF、市值型 ETF、權值龍頭、今年的題材股、融資追題材

第三項原本是「押多少」（三成倉／半倉／滿倉）。那是抽象的曝險刻度，不是股票市場：
散戶不會想「我要 62% 曝險」，他想的是「我要買 0050 還是台積電還是航運」。
改成標的之後，配息、換手（證交稅）、波動、流動性都自然跟著標的走，不必再另外補規則。

十九歲時選一次**流派**，不可逆：存股派／波段派／當沖派／套利派／長線派。同一顆種子換流派＝五條完全不同的路。

## 種子

`?seed=xxxxx` 決定這二十四年的完整牛熊。**相同種子＋相同選擇＝相同人生。**

- **戰帖**：結局頁可複製一條把整局結果編碼進去的網址（152 字元，不需後端）。對方拿到同一顆種子，而且你的淨值曲線會變成他畫面上的灰線。
- **鬼影**：同一顆種子重玩時，上一局的曲線會疊在你的線上。
- **圖鑑**：24 種結局、10 種特質、5 種流派的解鎖進度存在 localStorage。

## 兩條階梯

借自棒球生涯模擬的結構——聯盟階級，以及球團要不要跟你續約。

**資本階級**（你站在哪個舞台，會掉下去）
`散戶 → 中實戶 600萬 → 大戶 3000萬 → 隱形富豪 1.5億`

**受託關係**（有沒有人要你）
`自己的錢 → 家人的錢 → 朋友湊的 → 代操合約 → 私募基金`

管別人的錢會抽管理費 1.5% 與績效費 15%，但連兩年虧損就會被贖回。虧損年還得對投資人交代——照實說、強調長期、或者年底做帳把難看的部位換掉。

三十三歲還在散戶這一層，槓桿選項會永久消失。不是規則禁止你，是你輸不起了。

## 台股制度

不是換詞彙而已——這四項制度會改變你的決策：

- **證交稅 0.3%（賣出課稅）**：台股不管賺賠，賣掉就抽千分之三。所以吃掉報酬的是**換手率**，不是賺賠。各流派的年換手次數不同（存股 0.15、波段 2.6、當沖 9.5），稅費因此從 0.06% 到 2.2% 不等——當沖派每年繳的稅比多數人一整年的 α 還多。現股當沖證交稅減半，這也照做了。
- **漲跌幅 ±10%，跌停鎖死**：崩盤年選擇「全部砍掉」時，有機率賣不掉——委賣單掛在跌停價，排在幾萬張後面。盤感與情報越高越跑得掉。這是美股沒有的處境，也是台股最有辨識度的一件事。
- **除權息與填息**：除息當天股價直接扣掉股利，帳面一毛沒賺；要**填息**才算真的到手，貼息就是左手換右手。股利超過兩萬還要扣二代健保補充保費 2.11%。
- **三大法人買賣超**：情報提示不是抽象的「偏多偏空」，是「外資連續買超，投信同步加碼」「融資追繳簡訊開始發」。

## 對照組

結局會拿你跟三個同期、大盤、台積電算總帳。兩條對照線都用**跟你一模一樣的薪水、每年全部投入**去跑，所以差距完全來自選擇，不是本金。

## 技術

單檔 HTML，約 128 KB，沒有框架、沒有打包工具、沒有後端。

- **PRNG**：xmur3 字串雜湊 + mulberry32。整份程式只有一個隨機狀態。
- **鐵律**：任何純呈現層（動畫、圖表、HUD、時間軸）一律禁止呼叫 `R()`。骰子的滾動動畫刻意用 `Math.random()`——多消耗一次種子化亂數，後面整條人生就會錯位。
- **行情**：markov 鏈生成，校準到稳態算術年均約 11.9%、**幾何年化約 7.8%**。幾何遠低於算術是刻意的——波動本身就在吃掉報酬，那是這款想講的第一件事。
- **儲存**：localStorage 只放 UI 偏好、圖鑑與種子歷史，全部包在 try/catch 裡。沒有 localStorage 時遊戲照常能玩。

## 要看有多少人玩

內建 [GoatCounter](https://www.goatcounter.com/) 埋點：免費、不放 cookie、不需要同意橫幅。

1. 到 goatcounter.com 註冊一個站台代碼（例如 `gootsai`）
2. 打開 `index.html`，把 `const GC_CODE = ''` 改成 `const GC_CODE = 'gootsai'`
3. `git push`，一分鐘後就開始收數據

**留空則整段完全不動作，不會發出任何請求。**

除了瀏覽數，這些事件已經接好：

| 事件 | 意義 |
|---|---|
| `start-<動機>-<full\|fast>` | 有人真的按下開戶，以及選了哪種節奏 |
| `school-<流派>` | 十九歲選了哪一派 |
| `end-<結局id>` | 玩到最後，拿到哪個結局（24 種） |
| `cls-<0..3>` | 最高爬到哪個資本階級 |
| `share-challenge` | 有人複製戰帖連結 |
| `arrive-challenge` | 有人是從別人的戰帖連結進來的 |

`start` 對 `end` 的比值就是完成率；`share-challenge` 對 `arrive-challenge` 是傳播係數。
種子與戰帖碼一律歸到首頁路徑，免得每個連結都變成一筆新頁面。

## 安全

沒有後端、沒有帳號、沒有 cookie，也沒有任何金鑰在版控裡。但靜態網站不等於沒有攻擊面：

- **輸入清洗**：`?seed=` 與戰帖碼裡的對手姓名都會流進 `innerHTML`，而戰帖連結本來就是設計來給別人點的——這曾經是一個可用的 XSS。現在在**入口**做白名單（允許英數、連字號、底線與中日文字），而不是在十幾個輸出點各自逃逸；少逃逸一處就破功。輸出端另外再逃逸一層作為縱深防禦。
- **共用來源的風險**：`ishoplus.github.io` 是所有 GitHub Pages 專案共用的 origin，這一頁被打，同來源其他專案的 localStorage 也一起賠進去。這是把它當回事修的原因。
- **CSP**：單檔遊戲全部 inline，`script-src` 必須留 `'unsafe-inline'`，所以 CSP 擋不住注入的事件處理器——真正的防線是輸入端。CSP 擋的是外部腳本、外掛物件、`base` 標籤劫持與表單外送。
- **外部連線**：Google Fonts（會讓 Google 拿到訪客 IP）；啟用埋點後多一個 GoatCounter。其餘全部內嵌。
- **localStorage**：只有 UI 偏好、結局圖鑑與種子歷史。姓名是玩家自己填的，不會離開瀏覽器。

回歸測試涵蓋 5 種 payload × 4 個注入點。

## 事件卡的條件

有些卡的敘述斷言了玩家的狀態——帳上八萬的人不該抽到「帳戶破千萬那天」，
全職操盤的人也不該遇到「老闆發現你上班看盤」。14 張卡因此有 `if` 條件，
抽牌時會依當下的淨值、年齡、身分過濾。

實測：帳上 8 萬的高中生可抽 57 張、26 歲全職操盤 55 張、38 歲上班族 67 張。
